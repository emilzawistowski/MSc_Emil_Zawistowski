READING GUIDE FOR THE DISCUSSION SECTION:
  - MDE_Cohen_d_80pct_power: the minimum detectable effect (MDE) at
    N and alpha for this test. True effects at or above this size
    would have been detected with >= 80% probability.
  - MDE_uV_at_observed_SD: the same MDE expressed in microvolts,
    using this test's own observed between-subject SD, for direct
    comparison against amplitudes reported in the Results chapter.
  - Observed_d / Achieved_power_at_observed_d are reported for
    context only (per APA/Hoenig & Heisey guidance, post-hoc power
    computed from the observed effect should not be used as the
    primary sensitivity statistic; MDE above is).
